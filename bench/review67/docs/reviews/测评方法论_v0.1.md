# 测评方法论 v0.1：中文长期记忆检索的跨方案横评

> dsh-bounty #67 交付物之一。各方案报告（`lingshu_v0.1.md`、`mem0_v0.1.md`、`basic-memory_v0.1.md`）都按本文口径读数。
> 所有读数由 `bench/review67/` 下的脚本产生（一键：`bash run_all.sh`；只打印已有读数：`bash pairs.sh all`），判分是纯字符串、下标比较，不调用任何 LLM。

## 0. 意图声明

- **要测什么**：同一份中文语料逐条写入各方案的记忆层，再用自然语言问句检索，看**人工标注的证据**能否进入 top-10。
- **不测什么**：答案生成质量、LLM 抽取或改写记忆（Mem0 `infer=True`）、云端或付费嵌入、多用户隔离与并发、写入后的记忆演化（遗忘、冲突、合并）。这些都会引入 LLM 或不可锁定的外部服务，不能机械复核。
- **为什么只测检索层**：检索是「记得住、找得到」里唯一能在不调用 LLM 的前提下逐题判对错的环节；检索漏掉的证据，下游生成也补不回来。

## 2. 套件与金标（全部公开数据，锁定 commit + sha256）

| 套件 | 来源（锁定） | 规模 | 金标 | 判分 |
|---|---|---|---|---|

| `zh4o` | cows21/MOOM-Roleplay-Dialogue@942927e ZH-4O | 28 段对话、34861 条消息 / 1068 题 | 人工标注的证据消息下标 | 证据@10、窗口@10（允许 ±1 条）、MRR@10 |

- **写入**：每条 doc 一个记忆单元，按语料顺序逐条写入；不做任何预处理，各方案看到逐字相同的文本（`tasks.py` 生成）。
- **查询**：只用题干，ZH-4O 去掉 ABCD 选项；top-k 固定为 10。
- **zh4o 的「逐字相同」口径**：正文完全相同的两条消息（如「用户：嗯」）不可区分，判分时视为同一条。这条口径对所有方案一致生效。
- **`locomo` 无干扰版已饱和**：参照基线 hit@10 = 100%，只用来暴露「词法完全失效」的路径，不用来排序方案。

## 3. 对照设计（每家至少一组「基线 vs 方案」）

1. **共同量尺**：每家都和 `ref_bm25` 做配对比较（同一批题）。
2. **方案内拆解**：只改一个开关，其余不动。
   - 灵枢：`legacy`（上游默认）→ `fts_ctx` → `fts_ctx_anchor`（未合并开关，单列）
   - Mem0：`dense_only`（关掉关键词分支）→ `default`（产品默认的混合打分）
   - basic-memory：`text`（FTS5）／`hybrid_en`（默认模型）／`hybrid_zh`（换中文模型）／`hybrid_zh_t0`（再关掉默认 `semantic_min_similarity=0.55` 截断）
3. **差值的不确定度**：配对自助法，以题为重采样单位，2000 次，种子 0，报 95% CI。CI 不跨 0 才写成「提升」或「下降」；跨 0 的写成「差异不显著」。

## 4. 机械判据（结论措辞规则）

| 结论措辞 | 判据 |
|---|---|
| 「优于 / 低于参照基线」 | 配对差值的 95% CI 不含 0 |
| 「与参照基线持平」 | 95% CI 含 0 |
| 「某分支对某类查询无可测贡献」 | 开、关该分支的配对差值 95% CI 含 0；若差值恰为 0，同时报告 top-10 逐题相同的题数 |
| 「某路径对中文问句零召回」 | 该配置下全部题目返回 0 条结果 |
| 「接入正确」 | `selfcheck` 上 hit@10 ≥ 85%（原文片段应能被召回；低于此值的方案在报告里单独解释原因） |

报告里不使用「更好」「体验更佳」一类没有对应读数的措辞。

## 5. 可信边界

- **已验**：上表全部读数可由 `run_all.sh` 复跑；灵枢、ref_bm25 在同一机器上重跑时 top-10 逐位相同（Mem0 见其报告）；basic-memory 混合检索重跑时**分数相同、但 top-10 顺序有少量变动**（`hmb_B` 上 77/84 题顺序完全相同，82/84 题集合相同），见该方案报告。
- **未验**：GPU 或其他 CPU 指令集下嵌入的浮点差异；Windows / macOS（只在 Linux x86_64、Python 3.12.15 上跑过）；各方案写入大规模语料（> 4 万条）时的读数；Mem0 `infer=True` 与云端嵌入。
- **不确定**：ZH-4O 有 1 道题标签疑似损坏（qa 文本含葡萄牙语 `coleção`），保留未剔除，对所有方案影响相同；hmb 引文定位用的是「整句或任意 10 字连续片段命中」，少数引文可能落到相邻块。

## 6. 预期结果（测前写下）与实测对照

| 预期 | 实测 |
|---|---|
| 纯词法、未分词的路径（basic-memory `text`、Mem0 的 BM25 分支）在中文整句问句上接近零贡献 | 成立：basic-memory `text` hmb_B 84/84、zh4o_s4 159/159 返回空；Mem0 关掉 BM25 分支在 hmb_B / zh4o / zh4o_s4 上 Δ 的 CI 含 0 |
| 同一中文嵌入模型下，Mem0 与 basic-memory 在同一水平，差异来自截断与融合 | 部分成立：hmb_B 上 basic-memory 需关掉 0.55 阈值才到 27.2（Mem0 27.8）；zh4o_s4 上 basic-memory 23.9 高于 Mem0 19.5（两者未做配对检验） |
| ZH-4O 角色扮演长对话，任何方案证据@10 都不超过 40% | 成立：全量最高 30.0，前 4 段最高 33.3 |
